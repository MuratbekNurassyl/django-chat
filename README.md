# 💬 Django Chat Web App

A simple chat web application built with Python and Django.

##  About the Project

This project is a web-based chat application where users can register and exchange messages. It is somewhat similar to popular apps like WhatsApp and Snapchat.

##  Features

- User registration
- User accounts
- Sending messages
- Editing messages
- Django forms
- SQLite database
- HTML templates

##  Technologies

- Python
- Django
- HTML
- SQLite
